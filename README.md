# Team Project - Version Control Workflow (Exp-15)

## Branching Strategy
- `main`: Production-ready stable code.
- `module-auth`: Authentication module development.
- `module-dashboard`: Dashboard module development.

## Workflow Followed
1. Created individual feature branches from `main` for each module.
2. Pushed module commits to remote branches and opened Pull Requests (PRs).
3. Performed code reviews on PRs before merging into `main`.
4. Resolved merge conflicts in `config.txt` caused by simultaneous edits across module branches.
